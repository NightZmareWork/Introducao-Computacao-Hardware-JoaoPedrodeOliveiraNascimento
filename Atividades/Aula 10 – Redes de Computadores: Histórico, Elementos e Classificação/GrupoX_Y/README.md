# Aula 10 – Redes de Computadores: Histórico, Elementos e Classificação
O  trabalho realizado no dia 20 de abril tem como objetivo compreender a evolução das redes de computadores, identificar seus elementos básicos e classificar diferentes tipos de redes.
Foram criados para o trabalho:
- Uma linha do tempo breve da história e evolução da internet;
- Um esquema visual destacando os elementos de rede num exemplo real concreto do envio de uma mensagem de WhatsApp de um Smartphone para outro;
- Um esquema visual da classificação dos tipos de rede (PAN, LAN, MAN e WAN) com seus respectivos exemplos.
